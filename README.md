Arrays in C
This repository contains C programming exercises focused on the use of arrays to store, manage, and process data. The activities explore one-dimensional, two-dimensional, and three-dimensional arrays through a hotel management system.
 1D Array – Weekly Revenue Tracker

A program that stores the hotel's daily revenue for seven days using a one-dimensional array.

The program:

- Accepts revenue values for each day of the week.
- Calculates the total weekly revenue.
- Calculates the average daily revenue.

Q2. 2D Array – Room Occupancy (One Branch)

A program that uses a two-dimensional array to represent hotel room occupancy across five floors, with ten rooms on each floor.

The program:

- Represents occupied rooms using "1" and vacant rooms using "0".
- Accepts or simulates room occupancy data.
- Displays the number of occupied and vacant rooms on each floor.

Q3. 3D Array – Multiple Branches

A program that uses a three-dimensional array to represent room occupancy across three hotel branches, with five floors and ten rooms per floor.

The program:

- Stores room occupancy data for all branches.
- Assigns occupancy values of "1" or "0" to each room.
- Calculates and displays the total number of occupied rooms across all branches.

Learning Objectives

The purpose of these exercises is to develop an understanding of how arrays organize multiple values under a single variable name, and how multidimensional arrays can be used to represent real-world data.
